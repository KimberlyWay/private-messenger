# Private Messenger

Личный Android-мессенджер со сквозным шифрованием на Matrix Rust SDK и собственным интерфейсом Jetpack Compose Material 3.

Сервер: Synapse, PostgreSQL, шлюз открытой регистрации и Caddy в Docker Compose. Приватный логин для входа отделён от публичного `@username`. Тексты сообщений и вложения шифруются на клиентских устройствах.

Подробная инструкция и Android-клиент добавляются в следующих коммитах. До прохождения интеграционных проверок этот коммит не является готовым выпуском.
