# Lean — ваши люди, на вашей волне

Версия 0.6.0: один вход по логину и паролю, переписка и вложения доступны на любом устройстве без подтверждения на старом телефоне и без ключей восстановления.

Соединение защищено HTTPS/TLS. Сообщения и файлы хранятся на сервере и доступны его владельцу; сквозное шифрование облачных чатов не используется. Локальная база Android остаётся зашифрованной.

## Обновление

Обновите сервер и приложения обоих собеседников вместе. Существующие аккаунты продолжают работать через один экран входа. Сервер автоматически добавит отдельную ссылку на облачный чат для каждой пары; удалять базу или аккаунты не требуется. Старую зашифрованную историю без прежних ключей перенести нельзя — новая история начинается в облачных чатах.

См. [установку сервера](server/README.md), [вход и историю](docs/RECOVERY.md), [модель защиты](SECURITY.md).

## Возможности

- Личные чаты, фото, видео, голосовые и видеокружочки до 50 МБ.
- Автоматическая история и вложения после входа с другого устройства.
- Публичный username для поиска, отдельный приватный логин для входа.
- Аватары, отображаемое имя и оформление интерфейса.
- Удаление переписки у себя синхронизируется между устройствами аккаунта.

Управляемая синхронизация повторяет запросы после ошибок и переподключается после возвращения сети и открытия приложения. Статус подключения отображается в заголовке. Живые уведомления поддерживаются фоновой службой с постоянным уведомлением Android (не FCM). Разрешите уведомления; после принудительной остановки приложения откройте его снова. Ограничения энергосбережения Android могут задерживать фоновые подключения.

## Проверки и сборка

GitHub Actions проверяет Android-сборку, lint, настоящий сервер и обмен сообщениями на эмуляторе. Тесты включают вход с обоими прежними форматами пароля через один метод, историю и фото на новом устройстве, несколько одновременных устройств и удаление чата.

Android: JDK 21, Android SDK 37, `./gradlew assembleDebug assembleE2e assembleE2eAndroidTest lintDebug`. Интеграция: изолированный Docker-сервер и `./gradlew connectedE2eAndroidTest`. Подписанные релизы используют существующий постоянный ключ.

## Lean 0.6.0

Material 3 Expressive: компактная строка отправки, тональные поверхности Monet, новое оформление входа и адаптивный значок гранёного стакана. Настройки разделены на профиль, оформление, размер интерфейса, уведомления, память, диагностику и сведения о приложении.

Долгое нажатие открывает меню сообщения с размытием фона: ответ, копирование, пересылка, отметка, множественный выбор и удаление. Удаление «у меня» и отметки синхронизируются между устройствами аккаунта; удаление «у всех» через Matrix redaction разрешено только для собственных сообщений. Оно не отзывает сохранённые участником копии файлов. Отмена доступна для удаления у себя.

Профиль собеседника открывается по имени или аватару. Имя, статус, форма аватара и последние 12 фото профиля доступны другим авторизованным пользователям. Просмотр фото поддерживает масштабирование. Поддерживаются пять форм аватара. Дополнительные данные профиля хранятся в gateway; обновите сервер до 0.6.0 перед установкой клиента. Миграция добавляет таблицы без сброса аккаунтов и переписок.

Пакет Android и ключ подписи сохраняются, поэтому Lean устанавливается поверх Private Messenger. Проверки создают снимки реальных Compose-экранов в светлой и тёмной темах.
