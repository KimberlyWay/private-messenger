# Private Messenger — облачные чаты

Версия 0.5.0: один вход по логину и паролю, переписка и вложения доступны на любом устройстве без подтверждения на старом телефоне и без ключей восстановления.

Соединение защищено HTTPS/TLS. Сообщения и файлы хранятся на сервере и доступны его владельцу; сквозное шифрование облачных чатов не используется. Локальная база Android остаётся зашифрованной.

## Обновление

Обновите сервер и приложения обоих собеседников вместе. Существующие аккаунты продолжают работать через один экран входа. Сервер автоматически добавит отдельную ссылку на облачный чат для каждой пары; удалять базу или аккаунты не требуется. Старую зашифрованную историю без прежних ключей перенести нельзя — новая история начинается в облачных чатах.

См. [установку сервера](server/README.md), [вход и историю](docs/RECOVERY.md), [модель защиты](SECURITY.md).

## Возможности

- Личные чаты, фото, видео, голосовые и видеокружочки до 50 МБ.
- Автоматическая история и вложения после входа с другого устройства.
- Публичный username для поиска, отдельный приватный логин для входа.
- Аватары, отображаемое имя и оформление интерфейса.
- Удаление переписки у себя синхронизируется между устройствами аккаунта.

Синхронизация работает, пока приложение открыто. Фоновые push-уведомления пока не подключены.

## Проверки и сборка

GitHub Actions проверяет Android-сборку, lint, настоящий сервер и обмен сообщениями на эмуляторе. Тесты включают вход с обоими прежними форматами пароля через один метод, историю и фото на новом устройстве, несколько одновременных устройств и удаление чата.

Android: JDK 21, Android SDK 37, `./gradlew assembleDebug assembleE2e assembleE2eAndroidTest lintDebug`. Интеграция: изолированный Docker-сервер и `./gradlew connectedE2eAndroidTest`. Подписанные релизы используют существующий постоянный ключ.
