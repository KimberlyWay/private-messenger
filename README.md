# Личный чат

Личный Android-мессенджер для своего VPS. Нативный интерфейс на Kotlin и Jetpack Compose **Material 3 Expressive**, сквозное шифрование Matrix Rust SDK, сервер Synapse в Docker.

Проект находится в alpha. Рабочая опубликованная версия — в Releases; изменения в `main` могут ещё проходить проверки. Независимого аудита безопасности пока не было.

## Возможности

- Открытая регистрация, приватный логин и публичный `@username`, поиск собеседника.
- Личные зашифрованные чаты, фотографии, видео, голосовые до 3 минут и кружочки до 60 секунд. Вложения до 50 МБ.
- Имя и фото профиля. Редактор аватара: перемещение, приближение жестом или ползунком, круглый предпросмотр, сохранение выбранной области в JPEG 512×512 без исходных EXIF.
- Material You: цвета из обоев на Android 12+, полные палитры «Лаванда», «Океан», «Лес», «Роза», «Персик» и собственный оттенок. Google Material Color Utilities, спецификация 2026 для телефона.
- Светлая, тёмная и системная темы; чёрный фон для тёмного режима; контраст цветов, размер сообщений, скругление и компактность пузырей, тональный или градиентный фон. Предпросмотр и сброс оформления.
- Увеличение фотографий двумя пальцами и двойным нажатием, выделение и копирование текста.
- Проверка собеседника Matrix SAS и восстановление ключей из зашифрованной копии.

Пока не реализованы фоновые push-уведомления, звонки, групповой интерфейс, почтовый сброс пароля, редактирование/удаление сообщений и реакции. Синхронизация работает при запущенном приложении. Восстановление старой истории **пока требует ключа восстановления или доверенного устройства**; автоматическое восстановление по паролю ещё не включено.

## Установка и обновление

Скачайте `private-messenger-alpha.apk` из Releases. Универсальный APK содержит нативные библиотеки всех архитектур из зависимостей, поэтому имеет большой размер.

Для обновления установите новую версию поверх старой. `applicationId` — `uk.mywisp.privatechat`; ключ подписи постоянный. Подготовленная версия 0.3.1 использует `versionCode = 5`. Сеанс и настройки сохраняются при обычном обновлении. Удаление приложения не удаляет серверный аккаунт, но удаляет локальные ключи: возможность снова войти сама по себе не гарантирует расшифровку старых сообщений.

Сервер `https://144.31.107.221:8443` задан в `BuildConfig.DEFAULT_SERVER`. Пользователь вводит только логин и пароль; при регистрации также выбирает публичный username. Для своей сборки адрес меняется в `app/build.gradle.kts`. Существующие сеансы продолжают использовать сохранённый адрес.

## Разработка

Откройте корень проекта в Android Studio. Нужны JDK 21, SDK 37.0 и поддержка AGP 9.3.2; версию Gradle задаёт wrapper.

```bash
./gradlew assembleDebug lintDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`. Debug-сборка использует другой ключ и не заменяет подписанный релиз. Вариант `e2e` предназначен только для изолированного тестового сервера и не распространяется пользователям.

Проверки в Actions собирают Android, проверяют сервер и запускают реальный обмен зашифрованными сообщениями в эмуляторе: SAS, медиа, восстановление и отказ неподписанному устройству. Инструментальные тесты также проверяют регистрацию, профиль, редактор аватара и сохранение оформления. Успех проверяется для конкретного коммита.

Релиз запускается workflow `release.yml` с новым тегом вида `v0.3.1-alpha.1` после успешных Android, Server и E2EE проверок. Он использует существующие Secrets `ANDROID_KEYSTORE_BASE64` и `ANDROID_KEYSTORE_PASSWORD`, публикует APK, исходники, сервер и контрольные суммы. Ключ подписи не менять.

Код приложения: `app/src/main/java/uk/mywisp/privatechat/`. Палитры Google: `uk/mywisp/material/`, происхождение и лицензия — в [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md). Сервер: `server/`. Проверки: `app/src/androidTest/` и `server/tests/`.

## Исправление личных чатов в 0.3.1

Для обновления **нужно обновить серверный gateway**: он хранит единую комнату
для пары пользователей в PostgreSQL и сериализует одновременные запросы с двух
телефонов. Шифрование содержимого по-прежнему выполняет Matrix SDK на телефонах.
При первом открытии сервер может принять существующую зашифрованную комнату
ровно с этими двумя участниками. Повторный поиск не создаёт новые комнаты.
Старые дубликаты не удаляются: они доступны через «Прежние переписки» в чате.

Непринятые приглашения читаются из состояния приглашения, без запрещённого
запроса полного списка участников. Ошибки очереди видны отдельно от статуса
отправки. Переустановленное неподтверждённое устройство получает объяснение до
постановки сообщения в очередь, а не бесконечную «Отправку». Проверка другого
пользователя не заменяет подтверждение собственного устройства.

Новый тест проходит через два настоящих экземпляра MessengerRepository:
регистрация, приглашение, повторный поиск, одна комната, отправка в обе стороны
без обязательной ручной SAS-проверки, повторный вход и блокировка отправки с
неподтверждённого нового устройства. Серверный тест проверяет одновременные
запросы с обеих сторон и проверку принадлежности старой комнаты нужной паре.
